LEÇON 02 · LES NOMBRES

Compter de 1 à 1 000

Découvre les mots numériques de VÉRANKA, comprends leur construction, puis utilise le convertisseur et le mini-quiz.

Les nombres de 1 à 10

Les règles de construction

11 à 19 : Dek + unité. Exemple : Dek-An = 11.
Les dizaines : unité + Dek. Exemple : Du-Dek = 20.
Les nombres composés : dizaine + unité. Exemple : Du-Dek-Tre = 23.
Les centaines : multiplicateur + Kant. Exemple : Tre-Kant = 300.
Centaines composées : centaine + reste. Exemple : An-Kant-Du-Dek-Ven = 125.
1 000 : Milen.
